# Portfolio

Personal portfolio site.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The site is static HTML/CSS/JS and has no build step. Most project media is stored locally under `assets/`. The two TCP diagrams reference the original figures from Kieran Lamay's site, and the TCP demo slot is intentionally left as a placeholder for now.
